# Understanding Stripe Price IDs - Quick Guide

## ❌ What You DON'T Put in Environment Variables

You **DO NOT** put:
- ❌ Price amounts like `70` or `70€` or `"70€"`
- ❌ Numbers like `70`, `60`, `598`
- ❌ Currency symbols or formatted prices

## ✅ What You DO Put in Environment Variables

You **DO** put:
- ✅ **Stripe Price ID** - A unique identifier string that Stripe generates
- ✅ Format: `price_1AbCdEfGhIjKlMnOpQrStUv`
- ✅ This is a **string value**, not a number

---

## 🎯 Where to Get the Price ID

### Step 1: Create Products in Stripe Dashboard

1. Go to https://dashboard.stripe.com → **Products**
2. Click **Add product**

#### For Basic Plan:
- **Name**: `Basic Plan`
- Click **Add price**:
  - **Price**: `70.00` ← You enter the price HERE in Stripe
  - **Currency**: `EUR (€)`
  - **Billing period**: `Monthly`
  - **Recurring**: ✅ Yes
- Click **Save product**

#### For Pro Plan:
- **Name**: `Pro Plan`
- Click **Add price**:
  - **Price**: `60.00` ← You enter the price HERE in Stripe
  - **Currency**: `EUR (€)`
  - **Billing period**: `Monthly`
  - **Recurring**: ✅ Yes
- Click **Save product**

#### For Premium Plan:
- **Name**: `Premium Plan`
- Click **Add price**:
  - **Price**: `598.00` ← You enter the price HERE in Stripe
  - **Currency**: `EUR (€)`
  - **Billing period**: `Yearly`
  - **Recurring**: ✅ Yes
- Click **Save product**

### Step 2: Find the Price ID

After creating each product, you'll see:

**In the product page:**
- Product name: "Basic Plan"
- Price: €70.00 / month
- **Price ID**: `price_1AbCdEfGhIjKlMnOpQrStUv` ← **This is what you copy!**

**Where to find it:**
1. Go to **Products** → Click on your product (e.g., "Basic Plan")
2. Under the price section, you'll see:
   ```
   Price ID: price_1AbCdEfGhIjKlMnOpQrStUv
   ```
3. **Click to copy** the Price ID

### Step 3: Add to Your .env File

```env
# Frontend .env file
# These are STRINGS (text), not numbers!

VITE_STRIPE_PRICE_BASIC=price_1AbCdEfGhIjKlMnOpQrStUv
VITE_STRIPE_PRICE_PRO=price_1XyZaBcDeFgHiJkLmNoPqRs
VITE_STRIPE_PRICE_PREMIUM=price_1MnOpQrStUvWxYzAbCdEfGh
```

**Important:**
- ✅ These are **string values** (text)
- ✅ They start with `price_`
- ✅ They're unique identifiers generated by Stripe
- ✅ Each price ID is different for each product

### What Your Code Uses:
```javascript
// Your code uses the Price ID to tell Stripe which price to use
const priceId = import.meta.env.VITE_STRIPE_PRICE_BASIC;
// priceId = "price_1AbCdEfGhIjKlMnOpQrStUv"

// Stripe knows this Price ID = €70/month because you configured it in Dashboard
```

---

## 🔍 How It Works

1. **You configure the price in Stripe Dashboard** (€70, €60, €598)
2. **Stripe generates a unique Price ID** (`price_1AbCdEf...`)
3. **You copy the Price ID** to your `.env` file
4. **Your code uses the Price ID** to tell Stripe which price to charge
5. **Stripe knows the amount** because it's linked to that Price ID

## 💡 Why This Design?

Stripe uses Price IDs because:
- ✅ One product can have multiple prices (e.g., monthly vs yearly)
- ✅ Prices can change without breaking subscriptions
- ✅ Price IDs are unique and permanent identifiers
- ✅ Stripe handles currency, billing period, etc. automatically

---

## 📝 Summary

**You configure the price amount (€70, €60, €598) in Stripe Dashboard.**
**You copy the Price ID (price_1...) to your .env file.**
**Your code uses the Price ID to reference the price.**

The price amount is stored in Stripe, not in your environment variables!
